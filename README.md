### 🔭 Currently working on

- **M.Sc. thesis: vision–language–action models with joint verbal and action outputs** *(in progress)*
  The thesis argues that a compact VLA model can speak and act coherently at edge scale when it is distilled from a large language-native planner. The teacher, a fine-tuned mid-sized VLM, outputs actions as JSON to stay close to human-readable language; those action blocks are encoded into compact action tokens so the student can be deployed at the edge.

- **Language interfaces for upper-limb rehabilitation robots**
  I designed and built a fully local retrieval-augmented generation assistant for rehabilitation therapists and patients, built for patient privacy and closed hospital networks (ICROS 2026): versioned ingestion of clinical references, hybrid dense and full-text retrieval fused with Reciprocal Rank Fusion, and a locally served open-weight generator. I am now integrating it with an audio interface on the lab's rehabilitation robot and own the MLOps and service integration.
